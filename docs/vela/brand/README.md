# Vela brand

## Selected mark

Vela uses the **Fold / Indigo** identity:

- a folded `V` represents code transformation, reviewable diffs, and human/Agent collaboration;
- a deep indigo background connects the mark to an AI-native developer tool;
- warm cream, orange, coral, and rose facets provide contrast and preserve legibility at app-icon sizes.

Core colors:

```text
Indigo  #312E81
Night   #17112F
Cream   #FFEDD5
Orange  #FDBA74
Coral   #F58F7C
Rose    #F43F5E
```

Source and generation files in the Vela fork:

```text
assets/images/vela_logo.svg
crates/zed/resources/vela-app-icon*.svg
script/generate-vela-icons.py
```

The generated PNG application icons are committed because the application embeds them at build time. Dev, Preview, and Nightly use small channel-colored badges while retaining the same primary mark.
