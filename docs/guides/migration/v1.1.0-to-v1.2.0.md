# Migration Guide: v1.1.0 to v1.2.0 (Internationalization & WCAG AA Compliance)

## Overview
Zed v1.2.0 adds a full internationalization (`i18n`) architecture and verified WCAG 2.1 AA color contrast compliance algorithms across all themes.

## Key Changes

### 1. Internationalization Framework (`crates/i18n`)
All user-facing strings are now routed through the `i18n` crate:
```rust
// Previous (Hardcoded string):
let label = "Save File";

// New (Localized with dynamic fallback):
let label = i18n::t("file.save");

// Parameterized translations:
let msg = i18n::t_args("daemon.running", &[("addr", "127.0.0.1:9257")]);
```

### 2. Runtime Locale Switching
Locales can now be toggled on-the-fly via Rust API or JSON-RPC 2.0:
```rust
i18n::set_locale(i18n::Locale::ZhCn);
```
JSON-RPC:
```json
{"jsonrpc":"2.0","id":1,"method":"i18n/set_locale","params":{"locale":"ja"}}
```

### 3. Theme Accessibility Contrast Verification
Custom themes must verify minimum 4.5:1 contrast ratios for standard text via `theme::meets_wcag_aa(fg, bg, false)`.
