# `gpui-var-test.ttf`

A 1KB variable font generated by `generate.py` (fontTools), used only by tests.

It has a single `wght` axis (100 to 900, default 400) and one visible glyph, `A`,
drawn as a filled rectangle whose width and advance both grow with the weight:

| wght | advance | glyph x-extent |
|------|---------|----------------|
| 100  | 500     | 100..140       |
| 400  | 560     | 100..220       |
| 900  | 700     | 100..400       |

The outlines are plain rectangles authored here rather than derived from any
existing typeface, so the file carries no third-party licence. Regenerate with
`python3 generate.py` if the shape ever needs to change.
