# Theme-Aware LaTeX Math Rendering for Zed

This fork adds native LaTeX math rendering to Zed's markdown pipeline for the Assistant panel, with full theme reactivity.

## Theme Integration

Math expressions respect both the editor's **buffer font** and **color theme**:

- **Font** — uses `buffer_font.family` and `buffer_font.weight` from `ThemeSettings`, so inline math matches surrounding text exactly.
- **Color** — the current `theme().colors().text` is converted to a ratex `Color` and passed into katex-rs at render time (not post-processed). Switching Zed themes immediately updates the math glyph color.
- **Ascent alignment** — retrieves the actual font ascent via `cx.text_system().ascent()` to position inline math on the correct baseline, computed per-theme so it adapts to different font metrics.

## Architecture

```
Markdown source
  → Extracted math expressions (InlineMath / DisplayMath)
  → Parsed + laid out by ratex-layout
  → SVG generated by ratex-render with theme color injected
  → GPUI RenderImage cached by (latex_string, font_size)
  → Displayed inline or block via div/img elements
```

Cached results store the parsed display tree, not the final image — switching themes re-runs only the color pass, keeping memory low across many themes.
